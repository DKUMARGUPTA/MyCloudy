   192→   192→## 🔑 Technical Insights (reuse karo, dobara mat dhundo)
   193→   193→
   194→   194→- **⚠️ THE CANVAS-COMMIT RACE (P3.19, 4 ghante ka debugging!)**: Chrome accelerated OffscreenCanvas pe `page.render().promise` resolve hone par raster ops GPU pe PENDING reh sakte hain — us instant `convertToBlob()`/`getImageData()` **BLANK snapshot** de sakta hai (white ~49KB PNG jab committed ~87KB hona chahiye). Tesseract ko blank mila → conf 0 → errorOcrEmpty. **FIX: `committedPngBlob()`** (`tools/ocr-pdf/worker.ts`): convert → createImageBitmap(last) decode-yield → convert again → size-stability loop (deterministic PNG encoder = same bytes → same size). HAR tool jo render ke turant baad canvas padhta hai is guard se guzarna chahiye!
   195→   195→- **Hindi text layer in PDFs**: pdf-lib `drawText` + fontkit SHAPES Devanagari (visual glyph order) → extraction ि-matras rehint reorders → "दु िनया" (unsearchable). Char-by-char = dotted circles ◌. **SOLUTION: tesseract ka built-in PDF renderer** (`recognize(img, {pdfTitle}, {text:true, pdf:true})`) — GlyphLessFont + logical-order ToUnicode — "नमस्ते दुनिया" perfectly searchable. Page PDFs ko pdf-lib copyPages se merge karo.
   196→   196→- **Tesseract 7 self-host recipe**: `tesseract.esm.min.js` (default export = lib) + `worker.min.js` (nested classic worker, blob-wrapped importScripts) + 3× `-lstm.wasm.js` cores (SIMD variants auto-picked; single-file builds — no separate .wasm) + `langs/<lang>.traineddata.gz` from `@tesseract.js-data/<lang>/4.0.0_best_int/`. createWorker options: `{workerPath, corePath, langPath, gzip: true, workerBlobURL: true}` + `setParameters({user_defined_dpi, preserve_interword_spaces})`. OffscreenCanvas/Blob/dataURL sab loadImage handle karta hai — lekin committed blob best hai (upar wala race!).
   197→   197→- **QA harness pins (P3.19 naya)**: workspace state mein `main label` = OPTIONS ka label ho sakta hai — dropzone dhundo `textContent.includes('drop files here')` se (Hindi UI mein 'फ़ाइलें यहाँ')! Result ke baad drop karne se pehle "Start over" click karo. Toast errors dekhne ke liye MutationObserver lagao (auto-dismiss). `w.onmessage` pe addEventListener se progress/result capture karo.
   198→   198→- **HEIC decode recipe:** libheif-js@1.23.5 wasm-bundle.mjs (wasm EMBEDDED — single file, no separate .wasm) → copy to /public/libheif/, load via variable-URL dynamic import + turbopackIgnore (pdf.js pattern). Default export = FACTORY function — call it: `await factory()`. Then `new libheif.HeifDecoder().decode(bytes)` → image array → `image.display({data,width,height},cb)` fills RGBA. Empty array = corrupt/unsupported. Bun can smoke-test it directly!
