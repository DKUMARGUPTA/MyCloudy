   142→   142→## 5. Hard rules (from the user's master prompt + PRD — NEVER violate)
   143→   143→
   144→   144→- **Zero third-party CDNs** — fonts (Inter, Noto Sans Devanagari), icons, pdf.js, qpdf WASM,
   145→   145→  Tesseract traineddata all self-hosted from `/public`.
   146→   146→- **Device-only (mode D) tools: ZERO network requests with file data.** Heavy work in Web Workers,
   147→   147→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   148→   148→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   149→   149→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   150→   150→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   151→   151→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.
   152→   152→- **Accessibility**: keyboard operable, visible focus, aria labels, 44px targets,
   153→   153→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   154→   154→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   155→   155→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   156→   156→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   157→   157→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
   158→   158→- PRD §3.1 explicitly sets primary `#2563EB` (blue) — blue is the PRD-specified brand color here.
