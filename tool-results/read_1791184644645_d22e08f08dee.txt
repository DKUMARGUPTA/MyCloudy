    18→1\. Vision, Goals aur Principles
    19→
    20→1.1 Vision
    21→
    22→DocoPDF ek aisi website hai jahan user ko har PDF kaam (merge, split, compress, edit, sign, convert, OCR, secure) ek hi jagah, bina signup, tez aur private tareeke se mile. PDF24 jaise tools ki range, iLovePDF jaisa simple flow, aur PDFSimpli se behtar editor.

    24→1.2 Competitor gap
    25→
    26→| **Competitor** | **Kya achha**              | **Kya weak (hamara mauka)**                                                                |
    27→|----------------|----------------------------|--------------------------------------------------------------------------------------------|
    28→| PDF24 Tools    | 100+ free tools, no signup | UI purani aur crowded, tool pages me bahut text, editor basic, files server par jaati hain |
    29→| iLovePDF       | Clean 3-step flow, fast    | Editing weak, free limits, upload zaroori, signup nudges                                   |
    30→| PDFSimpli      | Editor aur templates       | Paywall aur subscription complaints, aggressive upsell, kam free tools                     |
    31→
    32→1.3 Goals (measurable)
    33→
    34→- **Privacy:** zyada-tar tools browser me chalein, file kabhi server par na jaaye (Device-only badge).
    35→
    36→- **Speed:** upload se download tak 30 second se kam (typical 5 MB file).
    37→
    38→- **Simplicity:** har tool 3 click me complete (Select, Option, Download).
    39→
    40→- **Editor:** Edit PDF Word jaisa easy ho, mobile par bhi chale.
    41→
    42→- **Coverage:** PDF24 ke saare tool categories + India-specific tools (GST invoice, Aadhaar/PAN redact, Hindi OCR).
    43→
    44→- **Growth:** SEO se organic traffic, har tool ka apna optimized page.
    45→
    46→1.4 Product principles
    47→
    48→- Privacy-first aur honest: jo tool server par chalta hai usse clearly "Server processing" badge dein, jhooth na bolen.
    49→
    50→- No dark patterns: forced signup nahi, hidden subscription nahi, cancel ek click me.
    51→
    52→- Mobile-first: India me zyada traffic mobile se hai. Touch targets 44px+, low-end Android par chale.
    53→
    54→- Bilingual from day one: English aur Hindi (Devanagari), baad me aur languages.
    55→
    56→- Self-hosted assets: fonts, icons, pdf.js, WASM, OCR language data sab apne domain se. Koi third-party CDN nahi.

    80→2.2 Do processing modes
    81→
    82→| **Mode**            | **Badge (UI)**                          | **Kya hota hai**                                                                         | **Privacy claim**                                                 |
    83→|---------------------|-----------------------------------------|------------------------------------------------------------------------------------------|-------------------------------------------------------------------|
    84→| D = Device-only     | Private - stays on your device          | Pura kaam browser me Web Worker me. File network par jaati hi nahi                       | "Your files never leave your device"                              |
    85→| S = Server-assisted | Server processing - deleted right after | File worker server par jaati hai, process hoti hai, result milta hai, file turant delete | "Deleted immediately after processing" (max 15 min fail-safe TTL) |
    86→
    87→**Rule:** Device-only tool par kabhi server call nahi honi chahiye. CI me ek test hoga jo in tools ke network requests check kare (file upload endpoint hit na ho).

   180→2.7 Server worker flow (S-mode tools)
   181→
   182→- Browser Vercel API se short-lived signed token leta hai (daily limit check hota hai).
   183→
   184→- Browser file seedha worker domain (jaise api.docopdf.com) ko bhejta hai. Vercel ki 4.5MB limit bypass hoti hai.
   185→
   186→- Worker job queue me process karta hai, result stream karta hai, aur temp files turant delete karta hai. Fail-safe cleanup har 5 minute me, max TTL 15 minute.
   187→
   188→- Worker par ClamAV scan, rate limit, size limit, aur sandbox (no network, resource limits).
   189→
   190→- Worker kuch log nahi karta jo file ka content ya naam ho. Sirf job id, tool, size bucket, duration, error code.
