   126→## 5. Hard rules (from the user's master prompt + PRD — NEVER violate)

   129→  Tesseract traineddata all self-hosted from `/public`.

   131→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   132→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   133→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   134→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   135→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.
   136→- **Accessibility**: keyboard operable, visible focus, aria labels, 44px targets,
   137→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   138→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   139→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   140→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   141→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
   142→- PRD §3.1 explicitly sets primary `#2563EB` (blue) — blue is the PRD-specified brand color here.
