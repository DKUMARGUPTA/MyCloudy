   132→  Tesseract traineddata all self-hosted from `/public`.

   134→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   135→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   136→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   137→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   138→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.

   140→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   141→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   142→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   143→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   144→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
