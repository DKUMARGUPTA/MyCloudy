   146→## 5. Hard rules (from the user's master prompt + PRD — NEVER violate)
   147→
   148→- **Zero third-party CDNs** — fonts (Inter, Noto Sans Devanagari), icons, pdf.js, qpdf WASM,
   149→  Tesseract traineddata all self-hosted from `/public`.
   150→- **Device-only (mode D) tools: ZERO network requests with file data.** Heavy work in Web Workers,
   151→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   152→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   153→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   154→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   155→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.
   156→- **Accessibility**: keyboard operable, visible focus, aria labels, 44px targets,
   157→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   158→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   159→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   160→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   161→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
   162→- PRD §3.1 explicitly sets primary `#2563EB` (blue) — blue is the PRD-specified brand color here.
   163→  Category colors: Organize=Blue, Edit=Purple, Convert=Green, Security=Red, Optimize=Orange,
   164→  Create=Teal, Invoices=Amber, View=Slate. Dark mode day one.
   165→- Sandbox extras: only `/` is user-visible; use API routes (`src/app/api`) not server actions;
