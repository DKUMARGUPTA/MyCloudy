   139→## 5. Hard rules (from the user's master prompt + PRD — NEVER violate)
   140→
   141→- **Zero third-party CDNs** — fonts (Inter, Noto Sans Devanagari), icons, pdf.js, qpdf WASM,
   142→  Tesseract traineddata all self-hosted from `/public`.
   143→- **Device-only (mode D) tools: ZERO network requests with file data.** Heavy work in Web Workers,
   144→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   145→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   146→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   147→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   148→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.
   149→- **Accessibility**: keyboard operable, visible focus, aria labels, 44px targets,
   150→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   151→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   152→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   153→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   154→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
   155→- PRD §3.1 explicitly sets primary `#2563EB` (blue) — blue is the PRD-specified brand color here.
   156→  Category colors: Organize=Blue, Edit=Purple, Convert=Green, Security=Red, Optimize=Orange,
   157→  Create=Teal, Invoices=Amber, View=Slate. Dark mode day one.
   158→- Sandbox extras: only `/` is user-visible; use API routes (`src/app/api`) not server actions;
   159→  never `bun run build`; check `dev.log` after coding; verify with agent-browser before reporting done.
