   134→## 5. Hard rules (from the user's master prompt + PRD — NEVER violate)
   135→
   136→- **Zero third-party CDNs** — fonts (Inter, Noto Sans Devanagari), icons, pdf.js, qpdf WASM,
   137→  Tesseract traineddata all self-hosted from `/public`.
   138→- **Device-only (mode D) tools: ZERO network requests with file data.** Heavy work in Web Workers,
   139→  never block the main thread. Mode S tools are Phase 3 (chat phase 11) only — do not build early.
   140→- **No AGPL/GPL libraries** (no Ghostscript, no MuPDF). Unclear license → flag "VERIFY", don't use.
   141→- **pdf-lib cannot encrypt** — Protect/Unlock must use qpdf WASM.
   142→- **Config-driven tools**: one registry + one shared ToolShell; never copy-paste per-tool pages.
   143→- **All UI strings via i18n keys** (en + real Hindi in Devanagari, short). Error copy per PRD §10 table.
   144→- **Accessibility**: keyboard operable, visible focus, aria labels, 44px targets,
   145→  prefers-reduced-motion, dark mode via §3 tokens. Mobile-first — mentally test at 360px first.
   146→- **No placeholder code / TODO / pseudo-code.** Every file complete and runnable.
   147→- **Pin exact package versions.** Unsure about an API → mark "VERIFY:" with the doc page; never guess.
   148→- **Security**: validate by magic bytes (not extension), size limits (50MB mobile / 200MB desktop
   149→  default per §2.4), CSP-friendly (no inline eval), NEVER log file names or contents.
   150→- PRD §3.1 explicitly sets primary `#2563EB` (blue) — blue is the PRD-specified brand color here.
   151→  Category colors: Organize=Blue, Edit=Purple, Convert=Green, Security=Red, Optimize=Orange,
   152→  Create=Teal, Invoices=Amber, View=Slate. Dark mode day one.
   153→- Sandbox extras: only `/` is user-visible; use API routes (`src/app/api`) not server actions;
   154→  never `bun run build`; check `dev.log` after coding; verify with agent-browser before reporting done.
